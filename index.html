Zero-cost architecture

      
Most "AI platform" demos die when the free credits run out. This one can't — there is nothing to pay for.

      
    
        
  1. Static hosting on GitHub Pages. The whole platform is HTML/CSS/JS. No server, no database, no cold starts, no bill.
    2. 
        
  2. The heuristic engine is pure JavaScript. Intent detection, the 7-dimension rubric, the rewriter, and the prompt library run in ~15 KB of code, instantly, on any device — including phones with no WebGPU.
    3. 
        
  3. LLM inference runs on your GPU via WebLLM + WebGPU. Opt in and the browser downloads Hermes-3 (Nous Research) or Qwen2.5 weights once from the Hugging Face CDN, caches them locally, and runs inference on-device. The site owner pays $0; your prompts never leave your machine.
    4. 
        
  4. Agents are declarative step specs. Each agent (classify → critique → rewrite → verify) executes client-side with a live trace — the same observability pattern used to debug production agent systems.
    5. 
        
  5. Pinned dependencies. WebLLM is pinned to a fixed version on a public CDN, so upstream changes can't silently break the page.
    6.
